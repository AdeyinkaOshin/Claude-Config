# Context file layout

The file always has these 10 sections, in this order. Keep it scannable: tables, short
lines, plain English. The skill `bunmi-weekly-context-file` (Step 4) holds the master version.

| # | Section | Contents |
|---|---|---|
| 1 | Header | Version · week covered and look-ahead · last refreshed · owner: Adeyinka · sources used (and which weren't available) · used by: Favour |
| 2 | How to use this file | Replaces reading the tech group; join calls only when the owner invites you · tier sits on the meeting, not the person · tier 1–3 need a one-page pre-read 24h ahead, else cut to 15 min or move and tell the owner · "TBC"/"not stated" mean the sources don't say |
| 3 | Tiers | 1 / 2 / 3 definitions |
| 4 | What changed this week | 3–8 labelled bullets (NEW, UP, DOWN, REMOVED, BOOKED, DATE MOVED, DON'T BOOK, TRAVEL) |
| 5 | Where Bunmi is | Table: date · location · notes, for the look-ahead. Then a numbered list of clashes |
| 6 | Priority meetings | One table per city: Tier · Meeting · VGG owner · Status (Booked: day, time, place / To book) · Context. Then a short paragraph on add-ons waiting for Bunmi's yes or no |
| 7 | Other live items that need Bunmi | Table: Item · VGG owner · What's needed from Bunmi · Next step/date · Booking status. Then dates to protect |
| 8 | Last week at a glance | Table: day · where Bunmi was · key meetings. Flags in-person invites while Bunmi was in another city |
| 9 | Open questions to settle before booking | Numbered, one line each, most urgent first |
| 10 | Keep out of this file | The keep-out list (see [`what-to-include-and-exclude.md`](what-to-include-and-exclude.md)) |

*Example "What changed" bullets (invented):*

```
- NEW · Tier 2 · Partner bank intro · owner: <VGG owner> · to book in week 2
- DATE MOVED · Board session from Tue to Thu
- DON'T BOOK · Strategy offsite: owner is setting it up directly
```
